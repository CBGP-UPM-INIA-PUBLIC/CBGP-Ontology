# CBGP-Ontology
Controlled Vocabularies for the CBGP Data Infrastructure


## Checking your edits before you push

Run `ruby check_ontology.rb` before committing - it catches labels with no language
tag, classes missing an English or Spanish label, and forms that would never be
listed, and tells you the line number of each. Step-by-step instructions:
**[SARA_README.md](SARA_README.md)**.
